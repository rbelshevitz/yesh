# Безопасность выполнения

yesh рассчитан на запуск с административными правами, поэтому опасные
неопределённости должны приводить к ошибке до запуска процесса.

## Запрещено в обычном режиме

```yesh
while true:              # нет: нет доказуемого конца
    echo loop

command &                # нет: неконтролируемый фоновой процесс
command |                # нет: pipe без потребителя
| command                # нет: pipe без источника
bash -c text             # нет: обход parser/runtime yesh
eval text                # нет: текст не становится кодом
```

## Ограничения runtime

- `for` принимает только конечные списки;
- количество итераций ограничено;
- внешняя команда имеет timeout;
- timeout pipeline отменяет всю process group, затем эскалирует SIGTERM → SIGKILL;
- зависший descendant не должен пережить завершение своей job-группы;
- pipeline состоит минимум из двух стадий и подключён к stdout или redirect;
- все стадии pipeline запускаются и ожидаются runtime;
- ненулевой exit status не теряется;
- в ошибке указываются файл, строка, команда и безопасно очищенный stderr.

Ограничения должны проверяться до запуска, где это возможно. Runtime не должен
создавать процесс, который потом окажется недостижимым из-за отсутствующего
читателя pipe.

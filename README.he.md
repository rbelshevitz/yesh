# yesh

שפה קריאה לאוטומציה ולבדיקות מקדימות בלינוקס, עם התנהגות מפורשת במקרה של
שגיאה.

yesh משאירה את כלי הלינוקס כפקודות חיצוניות גלויות ומוסיפה דרך קטנה וברורה
לתאר בדיקות, פעולות, סדר ביצוע ותנאי הצלחה. היא אינה מעטפת אינטראקטיבית ואינה
תחליף ל־Bash.

מחבר הפרויקט: Roman Belshevitz

## למי זה מתאים

לסקריפטים קטנים של ניהול ו־DevOps בלינוקס: גיבוי, פריסה, בדיקת שירותים,
פרסום תצורה ואבחון לקריאה בלבד. הפקודות `rsync`, `rsnapshot`, SSH ו־systemd
נשארות כלים חיצוניים; yesh מתזמרת אותן ואינה מחליפה אותן.

בדקו תחילה את הסקריפט במצב `--plan`:

```bash
./yesh --plan examples/hello.yesh
```

`--plan` מציגה את הפקודות ואת הארגומנטים ש־yesh מתכוונת להעביר, בלי להפעיל
פקודות חיצוניות ובלי לשנות קבצים באמצעות הפניות קלט/פלט.

## מצב הפרויקט

הפרויקט נמצא בפיתוח פעיל עבור Linux/amd64. `v0.2.0` מתמקדת בסקריפטים
ניתנים לבדיקה סביב גיבוי, `rsync`/`rsnapshot`, פרסום תצורה ותצפית סופית על
משאבי שירות. זו אינה מסגרת בטיחות לייצור ואינה מערכת ניטור כללית.

הדוגמאות והבדיקות מתארות את הגבולות שהוכחו בפועל. חלק מהן דורשות Linux,
systemd, SSH, הרשאות מנהל או סביבת בדיקה זמנית.

# yesh

yesh היא שפה וכלי לתיאור ולהפעלה של פעולות Linux מוגבלות, שבהן ברור מה יופעל,
מה עשוי להשתנות וכיצד תיבדק התוצאה.

yesh משאירה את כלי שורת הפקודה בלינוקס כפקודות חיצוניות גלויות ומוסיפה דרך
פשוטה וברורה לתיאור בדיקות, פעולות, סדר ביצוע ותנאי הצלחה. היא אינה באה
להחליף את Bash או את Ansible. היא מיועדת לפעולות Linux מוגבלות במשאבים ואחראיות, שבהן
טעות עלולה לעלות ביוקר: התוכנית גלויה לפני ההפעלה, והתוצאה ניתנת לבדיקה לאחריה.
בתרחישים כאלה קל יותר לקרוא ולבדוק סקריפט yesh מאשר סקריפט Bash שקול.

yesh אינה מסירה רק את הרעש התחבירי ההיסטורי של Bash. היא הופכת קוד הגנתי
חוזר לחלק גלוי וניתן לשימוש חוזר בסקריפט: בדיקות מקדימות, גבולות שגיאה,
בדיקת ארגומנטים, נעילות, ניקוי, תכנון ובדיקת התוצאה.
ההשפעה הרצויה דומה ליחס בין Go ל־Java: פחות טקסיות ופחות תשתית חוזרת,
בעוד שהפעולות עצמן נשארות גלויות.

מחבר הפרויקט: Roman Belshevitz

## למי זה מתאים

לסקריפטים קטנים לניהול Linux: גיבוי, פריסה, בדיקת שירותים, הפצת תצורה ואבחון
במצב קריאה בלבד. הפקודות `rsync`, `rsnapshot`, SSH, systemd ו־OpenRC נשארים
כלים חיצוניים; yesh מתזמרת אותם ואינה מחליפה אותם.

## מערכות Linux מוגבלות במשאבים

yesh תומכת בבדיקות שירותים תחת systemd וגם תחת OpenRC. במערכות המשתמשות ב־OpenRC,
כולל Alpine, היא יכולה להציג את הפלטפורמה ואת מנהל השירותים, את מצב
השירות ואת ה־PID שלו, את ה־cgroup ואת טבלת התהליכים, וכן מדידת משאבים לזמן
מוגבל עם היסטוריה מקומית בפורמט JSONL.

זה אינו ניטור רציף. הסקריפט עונה על שאלה מוגדרת במשך פרק זמן מוגבל ומציג גם
נתונים שאינם זמינים. תמיכה בבדיקת קונטיינרים היא כיוון עתידי בלבד, ותדווח רק
על נתונים הנראים מתוך הסביבה.

להשוואה מעשית, ראו את [מימוש הבסיס המפורש ב־Bash](examples/bash-rsync-incremental-baseline.sh)
לצד [התרחיש המקביל ב־yesh](examples/rsync-incremental.yesh). זו אינה קריקטורה
של Bash: המימוש מראה את הלוגיקה הידנית סביב `rsync`, כדי שאפשר יהיה להעריך את
ההבדל בקריאות ובבדיקה באותה פעולה.


הדגל `--plan` מציג את הפקודות ואת הארגומנטים ש־yesh מתכוונת להעביר, בלי להפעיל
פקודות חיצוניות ובלי לפתוח הפניות קלט/פלט.

## מצב הפרויקט

הפרויקט נמצא בפיתוח פעיל עבור Linux/amd64. הגרסה `v0.2.2` מתמקדת בליטוש
ותיקונים לסקריפטים הניתנים לבדיקה סביב גיבוי,
`rsync`/`rsnapshot`,
הפצת תצורה ומדידה מוגבלת של משאבי שירות. זו אינה מערכת בידוד או מנגנון בטיחות
לסביבת ייצור, ואינה מערכת
ניטור כללית.

הדוגמאות והבדיקות מתארות את הגבולות שהוכחו בפועל. חלק מהן דורשות Linux,
systemd, SSH, הרשאות מנהל מערכת או סביבת בדיקה זמנית.

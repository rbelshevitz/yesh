# yesh

שפת תכנות קריאה לאוטומציה ולבדיקות מקדימות בלינוקס, עם התנהגות מפורשת בעת
שגיאה.

yesh משאירה את כלי שורת הפקודה בלינוקס כפקודות חיצוניות גלויות ומוסיפה דרך
פשוטה וברורה לתיאור בדיקות, פעולות, סדר ביצוע ותנאי הצלחה.
היא אינה מעטפת אינטראקטיבית ואינה תחליף ל־Bash.

מחבר הפרויקט: Roman Belshevitz

## למי זה מתאים

לסקריפטים קטנים לניהול ול־DevOps בלינוקס: גיבוי, פריסה, בדיקת שירותים,
הפצת תצורה ואבחון במצב קריאה בלבד. הפקודות `rsync`, `rsnapshot`, SSH ו־systemd
נשארות כלים חיצוניים; yesh מתזמרת אותן ואינה מחליפה אותן.

בדקו תחילה את הסקריפט באמצעות `--plan`:

```bash
./yesh --plan examples/hello.yesh
```

הדגל `--plan` מציג את הפקודות ואת הארגומנטים ש־yesh מתכוונת להעביר, בלי להפעיל
פקודות חיצוניות ובלי לפתוח הפניות קלט/פלט.

## מצב הפרויקט

הפרויקט נמצא בפיתוח פעיל עבור Linux/amd64. הגרסה `v0.2.1` פורסמה; כעת
העבודה מתמקדת בליטוש ותיקונים לסקריפטים הניתנים לבדיקה סביב גיבוי,
`rsync`/`rsnapshot`,
הפצת תצורה ומדידה מוגבלת של משאבי שירות. זו אינה מערכת בידוד או מנגנון בטיחות
לסביבת ייצור, ואינה מערכת
ניטור כללית.

הדוגמאות והבדיקות מתארות את הגבולות שהוכחו בפועל. חלק מהן דורשות Linux,
systemd, SSH, הרשאות מנהל מערכת או סביבת בדיקה זמנית.
